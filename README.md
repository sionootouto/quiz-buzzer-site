# みんなで早押しクイズ

自由に出題・回答するオンライン早押しクイズです。スマホ・PC対応。点数・順位はありません。

## できること
- ルーム作成 / コードで参加（最大30人）
- 誰でも好きなタイミングで問題を出題。連続出題もOK
- テキスト問題 / 写真問題（画像は5MBまで、送信前に縮小）
- 早押しは最初の1人だけ回答権を取得
- 不正解者だけその問題の回答権を失い、他の人は再び早押し可能
- 正解、全員不正解、または出題者による問題終了で次の問題へ
- スマホ・PCの画面幅に対応

## 起動方法（Node.js 18以上）
1. Node.js 18以上をインストール
2. このフォルダでターミナルを開く
3. `npm install`
4. `npm start`
5. ブラウザで `http://localhost:3000` を開く

同じWi-Fi内のスマホから試す場合は、PCのローカルIPアドレスとポート3000を使います。インターネット越しに遊ぶには、Node.jsを動かせるホスティングサービスへこのプロジェクトをデプロイしてください。GitHub Pages単体ではSocket.IOのサーバーが動かないため、このアプリの公開先には使えません。

## 注意
- 現時点は試作版です。ルームはサーバーのメモリ上にあり、サーバー再起動で消えます。
- HTTPSの公開環境で利用してください。画像はルーム内に一時共有され、永続保存しません。
- 退出ボタンはページを再読み込みして接続を切ります。
